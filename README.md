# Onward
ONWARD — платформа, которая объединяет 5 небольших компаний для совместного найма одного начинающего специалиста. Компании делят между собой зарплату и задачи, а выпускник получает оплачиваемую работу, опыт и рекомендации от пяти работодателей. Главная цель: помочь выпускникам найти первую работу, а малому бизнесу — получить доступного сотрудника.
